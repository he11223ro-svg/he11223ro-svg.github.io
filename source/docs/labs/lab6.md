\## 3. Описание набора данных и первичный анализ

Датасет `Titanic` содержит информацию о пассажирах корабля. На этапе первичного анализа были выполнены следующие шаги:

\- Загрузка данных в DataFrame с помощью `pd.read\_csv`.

\- Проверка размерности, типов данных и выявление пропусков (наибольшее количество пропусков обнаружено в столбцах `Cabin` и `Age`).

\- Построение гистограмм распределения для числовых признаков (`Age`, `Fare`, `Pclass` и др.).



\---



\## 4. Обработка пропусков и трансформация данных



1\. \*\*Обработка Age:\*\* Пропущенные значения заменены медианным возрастом датасета. На основе возраста создан новый категориальный признак `Age\_group` (Child, Young, Adult, Senior).

2\. \*\*Обработка Embarked:\*\* Пропуски заменены наиболее частым значением (модой).

3\. \*\*Преобразование типов и новые признаки:\*\*

&#x20;  - Столбец `Pclass` переведен в строковый формат с заменой (`1 -> F`, `2 -> S`, `3 -> T`).

&#x20;  - Из столбца `Name` извлечен титул пассажира (`Title`).

&#x20;  - Поле `Sex` закодировано числовыми значениями (0/1).

&#x20;  - Созданы признаки `FamilySize` (общее число членов семьи) и `IsAlone` (флаг одиночного пассажира).



\---



\## 5. Обработка выбросов (Outliers)

\- С помощью метода \*\*IQR\*\* (межквартильного размаха) и построения boxplot были выявлены экстремальные значения стоимости билетов (`Fare`).

\- Применена процедура \*\*Winsorization\*\* для ограничения выбросов по цене билета, а для возраста (`Age`) экстремальные значения были заменены на 95-й перцентиль.

\## 6. Агрегация данных и метрики качества

В ходе группировки и анализа данных получены следующие закономерности:

\- Выживаемость пассажиров первого класса (`Pclass = 1`) существенно выше, чем у пассажиров третьего класса (`Pclass = 3`).
