# Лабораторная работа №1. Развертывание статического сайта

## Цель работы
Освоить процесс создания статического сайта с использованием генератора MkDocs и публикации на GitHub Pages.

## Задание
1. Создать публичный репозиторий.
2. Настроить MkDocs и тему оформления.
3. Развернуть сайт на GitHub Pages.

## Выводы
В ходе лабораторной работы были изучены основы работы с MkDocs, Git и GitHub Pages.
